# Mmacro Discord bot

Бот запускается макросом и читает токен из секции `[DiscordBot]` файла
`macro/ahk/settings.ini`.

## Установка

Откройте `Settings` → `Discord bot` и нажмите `Install dependencies`. Установщик:

- найдёт Python 3.10 или новее, а при необходимости установит Python 3.13 через winget;
- создаст локальное окружение `bot/runtime/.venv` без прав администратора;
- установит зависимости именно в это окружение;
- проверит импорт всех пакетов и сохранит путь к нему для запуска.

Повторная установка безопасна: она использует то же окружение и исправляет неполную установку.

Для ручной установки используйте виртуальное окружение, а не глобальный `pip`:

```powershell
py -3 -m venv bot/runtime/.venv
bot/runtime/.venv/Scripts/python.exe -m pip install -r bot/requirements.txt
```

## Команды

После добавления приложения на Discord-сервер доступны `/screenshot`, `/runs`, `/maps` и `/map <имя>`.

`GuildId` ускоряет появление slash-команд. Если `AllowedUserIds` заполнен, команды доступны только указанным Discord ID.

Токен является секретом: не публикуйте заполненный `macro/ahk/settings.ini`.
