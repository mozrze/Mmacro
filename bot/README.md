# Mmacro Discord bot

Бот запускается самим макросом и читает токен из секции `[DiscordBot]` файла `macro/ahk/settings.ini`.

Установить зависимости:

```powershell
python -m pip install -r bot/requirements.txt
```

Команды после добавления приложения на Discord-сервер:

- `/screenshot` — снимок игровой области;
- `/runs` — текущая карта, состояние фарма и количество ранов;
- `/maps` — список карт;
- `/map <имя>` — поставить карту в очередь после текущего раунда;
- Запись действий входа выполняется в макросе: выберите карту, нажмите отдельный хоткей `Map Entry Record`, выполните клики/колесо для входа на неё и нажмите хоткей ещё раз для сохранения. Discord-команда `/map <имя>` только ставит карту в очередь.

Для быстрого появления slash-команд укажите `GuildId` в настройках. Если `AllowedUserIds` не пустой, команды доступны только указанным Discord ID пользователей.

Токен является секретом: не публикуйте `macro/ahk/settings.ini` после его заполнения.
