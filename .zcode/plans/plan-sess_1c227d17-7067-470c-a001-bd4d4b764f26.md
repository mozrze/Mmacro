## План: Встраивание HTML-дизайна в AHK GUI через ActiveX

**Движок:** IE11 в Edge-режиме (Shell.Explorer + FEATURE_BROWSER_EMULATION). Причина: нулевые зависимости, работает на Win7–11.

### Что меняется в `main.ahk`:

**1. Строки 119–160 — GUI переписывается:**
- Убраны все нативные AHK-элементы боковой панели (кнопки, текст, DropDown, Edit)
- Вместо них — один ActiveX `Shell.Explorer` шириной 300px справа
- Игровая область слева — без изменений (AHK Text control)
- WebBrowser загружает `UI/index.html`

**2. Добавляется COM-мост AHK ↔ JS:**
- AHK вызывает JS: `wb.Document.parentWindow.execScript("ahkLog('text')")`
- JS вызывает AHK: `window.location.href = "ahk://embed"` → AHK ловит через `BeforeNavigate2`
- Реализованы функции-обработчики для каждой кнопки:
  - `ahk://embed` → BtnEmbed
  - `ahk://start-farm` → BtnStartStop
  - `ahk://select-map/Kings_Tomb` → MapChanged
  - `ahk://settings` → BtnSettings
  - `ahk://presets` → BtnOpenPresets
  - `ahk://calibrate` → BtnOpenCalibration
  - `ahk://snapshot` → BtnCaptureMap
  - `ahk://mark-slots` → BtnMarkSlots
  - `ahk://clear-map` → BtnClearMap
  - `ahk://toggle-autoupgrade` → AutoUpgradeToggle
  - `ahk://upgrade-cfg` → BtnOpenAutoUpgradeSettings
  - `ahk://clear-log` → очистка лога

**3. Добавляется AHK → JS стриминг лога:**
- `AddLog()` шлёт текст в JS-функцию `ahkReceiveLog(text)`
- Обновление координат, статуса — аналогично

### Что меняется в `UI/`:

**`style.css` — адаптация под IE11:**
- CSS-переменные → хардкод-значения
- `display: grid` → `display: flex` + `flex-wrap` + отступы
- `gap` → `margin`
- Добавлен `<meta http-equiv="X-UA-Compatible" content="IE=edge">`

**`script.js` — ES5 + мост:**
- `const`/`let` → `var`
- Стрелочные функции → обычные
- Шаблонные строки → конкатенация
- Mock-функции заменены на `window.location.href = 'ahk://...'`
- Добавлена глобальная функция `ahkReceiveLog(msg)` для приёма лога из AHK
- Добавлена глобальная функция `ahkUpdateStatus(text, cls)` для статуса

### Что НЕ меняется:
- Вся логика AHK: фарм-цикл, скриншоты, ImageSearch, SmoothMove, конфиги, пресеты
- Имена переменных
- Остальные окна (Settings/Presets/Calibration/AutoUpgrade/Mark/Snap) — остаются нативными AHK, но открываются по вызову из HTML

### Ожидаемый результат:
AHK-окно с игрой слева (1280×720) и современной тёмной HTML-панелью справа (300px). Все кнопки панели реально управляют макросом.
